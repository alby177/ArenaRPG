# ArenaRPG
This repository hosts the code for a simple RPG game developed with a C++ backend and a .NET frontend. 

It is a project to learn about project design, focusing on how to structure a project and on the prodcution of clean code.

## Tech stack
The backend is developed in C++ with a CMAKE build system in order to be cross platform. For the frontend, it's developed in Avalonia .NET in order to be cross platform as well.
