# VISION
This file contains the description of how the game is going to appear. 

ArenaRPG is a small tactical RPG focused on character customization and strategic combat rather than exploration.

The players are fighting into an arena which is represented by a map in which they can move freely according to their stamina. It's a 1 vs 1 game, players choose their character, customize it with weapons and armors to enhance the power of the moves and start battling against each other.

Fights can be player vs player or player vs AI.

The maps are full of obstacles, which can be a barrier for players or can slow they down. Players have to get around some of them or use others as traps for their enemy. Either way, obstacles can be traps or allies. 

Attacks can be either magical or physical, each character is specialized in one or the other equipments enhance the power of the attacker. The player can defend itself using magic or shields or using the obstacles around the map to block or slow down the enemy.
