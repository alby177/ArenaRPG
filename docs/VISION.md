# VISION
This file contains the description of how the game is going to appear. 

The game is played in a square field in which players can move freely. There are obstacles slowing down the players. The players fight in order to knock out the opponent(s). The fight can be physical and/or magical according to the player build. Each player cab be customized choosing the talent and the class and adding armors, weapons and spells (if availables).
